# إضافة Chrome لسحب بيانات ناجز - نظام إدارة المحاماة

## 📋 الوصف

هذه الإضافة تتيح لك سحب البيانات من منصة ناجز (القضايا، المواعيد، الوكالات) وإرسالها مباشرة إلى نظام إدارة المحاماة الخاص بك.

## ✨ المميزات

- 📋 سحب قائمة القضايا من صفحة القضايا
- 📄 سحب تفاصيل قضية محددة
- 📅 سحب المواعيد والجلسات من التقويم
- 📜 سحب بيانات الوكالات
- 🔄 مزامنة تلقائية مع قاعدة البيانات
- 🎨 واجهة عربية سهلة الاستخدام

## 🚀 التثبيت

### الطريقة الأولى: تحميل من المصدر (للتطوير)

1. افتح Chrome وانتقل إلى `chrome://extensions/`
2. فعّل "وضع المطور" (Developer mode) من أعلى يمين الصفحة
3. اضغط على "تحميل موسعة غير مجمعة" (Load unpacked)
4. اختر مجلد `najiz-chrome-extension`
5. ستظهر الإضافة في شريط الأدوات

### إنشاء الأيقونات

قبل التثبيت، يجب إنشاء الأيقونات بالأحجام المطلوبة:
- `icons/icon16.png` (16x16 بكسل)
- `icons/icon48.png` (48x48 بكسل)
- `icons/icon128.png` (128x128 بكسل)

يمكنك استخدام ملف `icons/icon.svg` كمصدر وتحويله للأحجام المطلوبة.

## ⚙️ الإعداد

1. افتح الإضافة من شريط الأدوات
2. أدخل رابط API الخاص بنظامك (مثال: `http://localhost:8000/api/v1`)
3. أدخل رمز المصادقة (API Token) إذا كان مطلوباً
4. اضغط "حفظ الإعدادات"
5. اضغط "اختبار الاتصال" للتأكد من الاتصال

## 📖 طريقة الاستخدام

### سحب القضايا

1. انتقل إلى صفحة القضايا في ناجز: `https://www.najiz.sa/applications/lawsuit`
2. افتح الإضافة
3. اضغط "سحب جميع القضايا" أو "سحب المحدد"

### سحب تفاصيل قضية

1. افتح صفحة تفاصيل قضية معينة في ناجز
2. افتح الإضافة
3. ستظهر معاينة للبيانات
4. اضغط "سحب وحفظ القضية"

### سحب المواعيد

1. انتقل إلى صفحة التقويم في ناجز
2. افتح الإضافة
3. اضغط "سحب جميع المواعيد"

### سحب الوكالات

1. انتقل إلى صفحة الوكالات في ناجز
2. افتح الإضافة
3. اضغط "سحب جميع الوكالات"

## 🔧 الصفحات المدعومة

| الصفحة | الرابط | الوظيفة |
|--------|--------|---------|
| قائمة القضايا | `/applications/lawsuit` | سحب جميع القضايا |
| تفاصيل قضية | `/applications/lawsuit/cases/case-file/*` | سحب تفاصيل قضية |
| التقويم | `/applications/lawsuit/calendar` | سحب المواعيد |
| الوكالات | `/applications/wekalat` | سحب الوكالات |

## 🔌 API Endpoints

الإضافة تتواصل مع النظام من خلال الـ API التالية:

- `POST /cases` - إضافة قضية جديدة
- `POST /cases/import` - استيراد قضايا متعددة
- `POST /appointments/import` - استيراد مواعيد
- `GET /simple/hello` - اختبار الاتصال

## 🔒 الأمان

- الإضافة تعمل فقط على موقع ناجز
- البيانات تُرسل مباشرة إلى الخادم المحلي
- لا يتم تخزين أي بيانات حساسة في الإضافة
- يمكن استخدام رمز مصادقة لحماية API

## 🐛 استكشاف الأخطاء

### الإضافة لا تتصل بالنظام

1. تأكد من أن خادم Laravel يعمل
2. تأكد من صحة رابط API
3. تحقق من وحدة التحكم (Console) في المتصفح

### لا يتم سحب البيانات

1. تأكد من تحميل الصفحة بالكامل
2. انتظر بضع ثوانٍ وأعد المحاولة
3. تحقق من وحدة التحكم للأخطاء

### شريط الأدوات لا يظهر

1. أعد تحميل الصفحة
2. تأكد من تفعيل الإضافة
3. تحقق من الصلاحيات في إعدادات Chrome

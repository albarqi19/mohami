# 📋 خطة تطوير نظام إدارة المهام لشركة المحاماة - Laravel Backend

## 🔍 تحليل النظام الحالي (مكتمل)

### ✅ المكونات المكتملة في Frontend:
- **نظام المصادقة**: تسجيل دخول مع أدوار مختلفة (Admin, Lawyer, Legal Assistant, Client)
- **إدارة المهام**: واجهة شاملة للمهام مع فلترة وبحث متقدم
- **إدارة القضايا**: عرض وإضافة القضايا مع التفاصيل الكاملة
- **إدارة الوثائق**: رفع وعرض المستندات مع التصنيف
- **سجل الأنشطة**: تتبع جميع العمليات والأحداث
- **التقارير**: إحصائيات وتقارير شاملة
- **التنبيهات**: نظام إشعارات متقدم
- **التصميم**: واجهة عربية متجاوبة مع الألوان المناسبة

## 🗄️ تصميم قاعدة البيانات Laravel

### 📊 جداول قاعدة البيانات المطلوبة:

#### 1. **جدول المستخدمين - users**
```sql
id (bigint, primary key, auto_increment)
name (varchar 255)
email (varchar 255, unique)
email_verified_at (timestamp, nullable)
password (varchar 255)
role (enum: 'admin', 'lawyer', 'legal_assistant', 'client')
phone (varchar 20, nullable)
avatar (varchar 255, nullable)
is_active (boolean, default true)
last_login_at (timestamp, nullable)
remember_token (varchar 100, nullable)
created_at (timestamp)
updated_at (timestamp)
```

#### 2. **جدول القضايا - cases**
```sql
id (bigint, primary key, auto_increment)
file_number (varchar 50, unique)

status (enum: 'active', 'pending', 'closed', 'appealed', 'settled', 'dismissed')
priority (enum: 'low', 'medium', 'high', 'urgent')
description (text, nullable)
contract_value (decimal 15,2, nullable)
filing_date (date, nullable)
due_date (date, nullable)
next_hearing (datetime, nullable)
notes (text, nullable)
created_by (bigint, foreign key to users.id)
```

#### 3. **جدول تعيين المحامين للقضايا - case_lawyers**

#### 5. **جدول الوثائق - documents**

#### اليوم 1: إعداد المشروع الأساسي
- [ ] إنشاء مشروع Laravel جديد
```bash

cd law-firm-backend
```

## 🛠️ التقنيات المستخدمة

### Backend (Laravel):
- **Framework**: Laravel 10
- **Database**: MySQL/PostgreSQL
- **Authentication**: Laravel Sanctum
- **Permissions**: Spatie Laravel Permission
- **File Storage**: Laravel Storage (S3/Local)
- **Image Processing**: Intervention Image

### Frontend (الموجود):
- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **State**: React Context API
- **HTTP Client**: Axios
- **UI Components**: Custom + Lucide Icons
